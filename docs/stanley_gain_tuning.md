# Stanley 조향 게인 튜닝 (2026-07-21)

## 대상 파라미터

`race_script.yaml` → `stanley_controller.py` 에서 쓰는 6개 게인.

```
steer_ff = ff_gain * atan(wheelbase * κ)                              # 피드포워드
steer    = steer_ff + gain * (yaw_err - atan2(k * cte, v + ks))       # 피드백
steer    = steer_lpf * steer + (1 - steer_lpf) * steer_prev            # 저역통과
```

(출처: `src/race_stack/race_stack/stanley_controller.py`)

<details>
<summary><b>파라미터별 의미</b></summary>

- **gain (stanley_gain)** — 피드백(요각오차 + 횡오차 보정) 전체에 곱하는 게인.
  ↑ 크면 경로 추종이 빡빡해지지만 너무 크면 좌우로 흔들림(오실레이션).
  ↓ 작으면 부드럽지만 코너에서 라인 이탈(cutting) 가능.

- **k (stanley_k)** — 횡방향 오차(CTE, 경로에서 옆으로 벗어난 거리)를 조향각으로 바꾸는 게인.
  ↑ 크면 라인 복귀가 빨라지지만 저속에서 과민/떨림.
  ↓ 작으면 복귀가 느려 코너 안쪽으로 파고들 수 있음.

- **ks (stanley_ks)** — 속도항 `(v + ks)` 의 소프트닝 상수.
  저속(출발/정지 근처)에서 CTE 게인이 과도해지는 것을 억제.
  ↑ 크면 저속에서 조향이 둔감·안정적. ↓ 작으면 저속에서 조향이 민감/떨림.

- **ff_gain** — 곡률 기반 피드포워드 게인. 오차가 생기기 전에 앞으로 올 코너
  곡률만 보고 미리 조향을 넣어줌.
  ↑ 크면 코너 진입을 더 일찍/과감하게 꺾음(반응성↑, 너무 크면 과도조향).
  ↓ 작으면 순수 피드백에 가까워져 코너 반응이 늦어짐.

- **ff_preview_sec** — 피드포워드가 몇 초 앞의 웨이포인트 곡률을 미리 보는지
  (서보 지연 보상). `preview 거리 = speed × ff_preview_sec`.
  ↑ 크면 더 먼 미래를 보고 미리 꺾음(고속에 유리, 너무 크면 실제 코너보다 일찍 꺾임).
  ↓ 작으면 지연 보상 부족으로 반응이 늦어짐.

- **steer_lpf** — 최종 조향각 저역통과 필터 계수. `1.0` 이면 필터 없음(즉시 반영).
  ↓ 낮추면 조향이 부드러워지지만 반응 지연 발생(너무 낮으면 코너를 못 따라감).

</details>

## 실주행 관찰 (2026-07-21) 및 튜닝 방향

RViz에서 웨이포인트(초록/빨강)와 실주행 궤적(파랑)을 비교한 결과:

- 파란 실주행 경로가 **코너 전 구간에서 일관되게 웨이포인트보다 바깥쪽으로 부풀어 있음**
  (네 모서리 전부 동일 패턴, 여러 랩이 거의 겹쳐서 반복됨 — 좌우로 흔들리는
  오실레이션은 없음)
- → 조향이 "떨려서" 생기는 문제가 아니라, 코너를 도는 힘 자체가 부족한
  **체계적인 언더스티어**로 판단

### 조절 우선순위

1. **`ff_gain` ↑ 먼저** (기존 0.8 → 1.1~1.3 정도로 소폭씩)
   코너 진입 시 미리 꺾는 각도를 키워 바깥으로 밀리는 것을 원천적으로 줄임.
   (현재 값 0.8 은 기준값 1.0 보다도 낮아 오히려 억제하고 있는 상태였음)
2. 그래도 밀림이 남으면 **`k` ↑** (1.0 → 1.2~1.3) — 벗어난 후 라인 복귀 속도를 높임
3. 1·2번 반영 후에도 부족하면 **`gain`** 소폭만 (1.5 → 1.6~1.7) —
   오실레이션이 관찰되기 시작하면 바로 되돌릴 것
4. **`ff_preview_sec`** (현재 1.0초) 은 밀리는 시점이 코너 시작 지점과 맞물려 보여
   지금은 우선순위 낮음. 1·2번 조정 후 "코너 진입 전부터 너무 일찍 꺾인다" 나
   "코너를 지나서도 계속 밀린다" 같은 타이밍 문제가 보이면 그때 조정
5. **`ks`, `steer_lpf`** 는 현재 패턴(부드러운 바깥쪽 편향, 떨림 없음)과 무관해
   보여 지금은 그대로 둠
