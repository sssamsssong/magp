## 1. 검증이 필요한 것 — 우선순위 순

### ① 라이다 수평화 + wall_skip 효과 확인 (제일 먼저, 주행만 하면 됨)

08/24 저녁 로그(6대 주행)에서 **트랙의 특정 5개 지점**에서 `n_obs` 가 매 랩
평균 340~540 개까지 튀었다. 그 뒤에 두 가지를 고쳤는데 **둘 다 미검증**이다:

- 라이다 마운트 물리적 수평화 (커밋 없음, 하드웨어)
- `raycast_wall_skip` 0.10 재적용 (`55f13d4`)

**할 것**: 평소대로 한 세션 돌리고 로그를 올린 뒤, 그 5개 지점
`(-5,1) (-7,-1) (-6,-1) (-7,0) (-6,2)` 의 `n_obs` 가 실제로 줄었는지 본다.

- 줄었으면 → 원인이 맞았다. 끝.
- 안 줄었으면 → 그 구간은 **맵 정제가 덜 된 것**이다. `./race.sh clean` 을
  더 공격적으로 다시 돌리거나 폴리곤 GUI 로 손봐야 한다.

### ② 충돌 복구 (stuck_recovery) — ★ 실차 미검증, 기본 꺼짐

충돌로 끼면 → 조금 후진 → 서서 자세 재정렬 → 컨트롤러 복귀.

```bash
cd ~/yax && ./tune.sh recovery.enabled=true    # 켜기 (기본 false)
```

**⚠ 처음 켤 때는 반드시 넓은 곳에서, 혼자, 일부러 끼워서 테스트할 것.**
6대가 도는 트랙에서 처음 켜지 말 것.

테스트 절차:
1. 넓은 곳에서 `./race.sh race` (또는 q2)
2. 차를 벽에 일부러 붙여 못 가게 만든다
3. 1.5초 뒤 `⚠ 끼임 감지` 로그가 뜨고 후진하는지 확인
4. 후진량이 40cm 근처인지, 그 뒤 정지 → `재정렬 요청` 로그 → 다시 달리는지 확인
5. 조이스틱 **LB 를 누르면 복구가 즉시 멈추는지** 확인 (이게 최후 안전장치다)

**⚠⚠ 후방 사각지대** — 2호차 라이다는 ±135° 라 **정후방 ±45° 를 못 본다.**
바로 뒤의 차를 모른다. 그래서 후진을 40cm / 2초 / 3회로 못박아 뒀다.
**이 값들을 키우기 전에 반드시 이 점을 다시 생각할 것.**

끄려면: `./tune.sh recovery.enabled=false`

### ③ `--self` 수동 위치지정 — 미검증

```bash
./race.sh race --self      # 자동 정렬 없이 RViz 로 직접 찍기
```

자동 정렬을 건너뛰고 RViz `2D Pose Estimate` 로 찍을 때까지 기다린다.
찍으면 **그 자세 그대로** 적합도만 재서 출발 게이트를 연다(몇 cm 맞는지 표시).

**같이 확인할 것**: `--self` **없이도** RViz 수동 지정 후 출발 게이트가 열리는지.
지금까지는 이게 **안 됐다** (`/race/localized` 미발행 버그, 이번에 같이 고침).

### ④ `race2` — 미검증

```bash
./race.sh start_pos        # 위치 찍어두고
./race.sh race2            # 격자탐색 없이 그 위치를 그대로 믿고 시작
```

기동 로그의 `평균오차 Ncm` 이 평소(`race`)와 비슷한지 본다.
