# 대회 당일 — 새 트랙/새 바닥 체크리스트 (매핑 5분 + 연습 5분)

전제: 처음 보는 바닥에서 맵핑 5분, 연습(주행) 5분만 주어진다. 시간이 절대적으로
부족하므로 **우선순위대로** 움직인다 — 매 단계 "이걸 못 끝내면 다음은 포기"
기준으로 짰다.

## 왜 이 순서인가 (구조적 제약)

- `./race.sh mapping-joy`(SLAM 맵핑)와 마찰력 측정은 **서로 다른 launch**다
  (`mapping.launch.py`엔 `slip_friction` 노드가 없다). 동시에 못 돌린다 —
  맵 먼저, 마찰력은 그다음 순번이다.
- `limits.grip_util` 스윕(속도 한계 찾기)은 **자율주행 스택 전체**가 있어야
  한다. 맵핑 시간엔 알고리즘을 못 돌리므로 **이건 연습 세션에서만 가능**하다.
- **바닥이 바뀌어도 안 바뀌는 값**은 이 자리에서 다시 잴 필요 없다 —
  `geometry.mass/lf/lr/wheelbase`(차량 하드웨어), `vesc` 조향 트림 등은
  바닥과 무관하다. 센서박스 장착처럼 **차체 자체가 바뀐 게 아니라면** 건드리지
  않는다. 바닥이 바꾸는 건 오직 **그립(`tire.mu`)** 뿐이다.
- ★ 2026-08-24 갱신 — 마찰력 측정에 `./race.sh slip`(D-pad로 반경 고정하고
  속도를 올리는 원형 주행 시험) **대신 `./race.sh joy2 --bag`**을 쓴다.
  평소처럼 조이스틱으로 몰기만 해도 `slip_friction`이 조용히 μ̂를 뽑아낸다
  (원 그리기 불필요). `slip` 모드는 마찰 한계를 넘기면 실제 회전반경이
  `v²/(μg)`로 커져 **넓게 트인 공간이 따로 필요**했는데, `joy2 --bag`는
  한계를 일부러 시험하지 않으므로 트랙 안에서 해도 안전하다.

## 0. 도착 전 / 대기 중 (시간 안 씀)

- [ ] `.car`가 `car2`인지 확인 (`cat .car`)
- [ ] 배터리 확인 (`bat.sh` 있으면)
- [ ] `./tune.sh status` — 지금 켜져 있는 값이 마지막 커밋 상태와 다른 실험값이
      남아있진 않은지 확인. 대회 전에 **깨끗한 기준값**으로 시작할 것
- [ ] `config/vehicle_car2.yaml`의 `tuning.grip_util`을 **보수적으로 리셋**
      해 둘지 결정 (예: 전 모드 0.4 근처) — 새 바닥 그립을 모르는 채로
      이전 바닥 값(q2 0.75 등)을 그대로 쓰면 첫 주행에 과속 위험
- [ ] 노트북 쪽 `./rviz.sh car2`(또는 IP 끝자리) 미리 붙여서 확인해둘 것 —
      맵핑 창에서 SLAM 진행 상황을 봐야 한다
- [ ] `race_script.yaml`의 `map_name`/`waypoints`는 **아직 존재하지 않는 새
      맵 이름**으로 미리 정해두기만 하고, 실제로 그 파일이 생기기 전엔 손대지
      말 것 (커밋 금지 — CLAUDE.md 트랙 설정 규칙)

## 1. 맵핑 창 (5분) — 목표: **완주 가능한 맵 하나**를 확실히 남긴다

우선순위: **맵 완성 > 마찰력 측정.** 맵이 없으면 그 다음 아무것도 못 한다.

- [ ] 터미널A (젯슨 또는 SSH): `./race.sh mapping-joy` — 켜 둔 채로 유지
- [ ] 조이스틱으로 트랙 **전체 둘레를 천천히 1~2바퀴** — 코너·벽 구석까지
      라이다가 잘 보이게, 급조향 없이
- [ ] **savemap을 A를 끄기 전에** 실행해야 한다 (Ctrl+C로 먼저 끄면 SLAM
      맵이 메모리에서 통째로 날아간다):
      터미널B: `./race.sh savemap <새맵이름>` (예: `0822_track`)
- [ ] 저장 확인 후에만 터미널A Ctrl+C
- [ ] **시간이 남으면(30초 이상)만** — `mapping-joy` 창을 끄고 이어서
      `./race.sh joy2 --bag`로 짧게 한 바퀴 더 돈다. 원 그리기 없이 평소처럼
      몰기만 하면 `slip_friction`이 배경에서 μ̂를 뽑아 `logs/slip_tests/`에
      쌓는다(2초 뒤 `imu_odom`, 6초 뒤 `slip_friction` 자동 기동). 시간이
      빠듯하면 **과감히 생략** — 이 값은 연습 세션의 η 스윕으로 어차피
      다시 확인한다.

⚠️ 맵핑 5분을 다 썼는데 맵이 부실하면(구석이 비어있음 등) — 그래도 있는 대로
쓴다. 재맵핑할 시간은 없다.

## 2. 창 사이 (오프클록 — 노트북에서, 시간 제한 없음)

이 구간은 시계가 안 돌아가니 침착하게. 다음 순서로:

- [ ] `./race.sh clean <새맵이름>` — SLAM 빛샘 제거. `<맵>_clean_preview.png`
      **반드시 눈으로 확인** (빨강 = 지워진 영역이 트랙을 깎아먹지 않았는지)
- [ ] 레이싱라인 생성 — 자동/비-GUI로 빠르게:
      `./race.sh line <맵>_clean --mu <지금까지 알고 있는 최선의 μ>`
      ⚠️ **`--mu`를 반드시 명시할 것** — 생략하면 기본값 0.90이 들어가
      실제 그립보다 훨씬 낙관적인(절반짜리 코너 나오는) 라인이 만들어진다.
      맵핑 뒤 `joy2 --bag`를 못 했다면 **직전 세션에서 마지막으로 실측된
      `tire.mu`** (지금 기준 0.45)를 일단 넣는다 — 어차피 실차 grip_util
      스윕이 최종 안전장치다.
- [ ] `./race.sh start_pos` — 새 맵 띄우고 두 번 클릭으로 출발 포즈 지정
      (스택 없이 가능, 시간 압박 없는 지금 해두는 게 안전). **2026-08-24부터
      이 명령이 `race_script.yaml`의 `map_name:`/`waypoints:`도 같이
      갱신한다** — 고른 맵 그대로 트랙 설정에 반영되니 따로 yaml을 손으로
      고칠 필요 없다 (그래도 커밋은 금지 — 트랙 설정은 아직 안 나눈 공유 값).
      디스플레이가 없는 순수 SSH면 `./race.sh set_map`으로 맵/웨이포인트만
      먼저 바꿔두고, 나중에 노트북에서 `start_pos --gui`로 출발 포즈만 잡아도 됨
- [ ] `config/vehicle_car2.yaml`의 `tuning.grip_util`을 **전 모드 보수적으로**
      맞춰둔다 (0단계에서 안 했다면 지금). 연습 세션에서 여기서부터 올린다
- [ ] `./tune.sh status`로 지금 뭐가 바뀐 상태인지 마지막으로 확인

## 3. 연습 세션 (5분) — 목표: **grip_util 안전 상한 확보 + quali 흐름 검증**

시간 배분 기준 (5분 = 300초):

| 구간 | 시간 | 내용 |
|---|---|---|
| ① 위치추정 확인 + (여유되면) 마찰력 보강 | ~30~60초 | `./race.sh box --bag`로 정지 상태 AMCL 정렬부터 확인, 여유 있으면 LB로 수동 전환해 한 바퀴 돌며 μ̂도 같이 모은다 |
| ② grip_util 저속 확인 | ~90초 | 보수값(예 0.4)으로 `./race.sh q1` 1바퀴 |
| ③ grip_util 한 단계만 상향 | ~90초 | 문제 없으면 `./tune.sh q1+=0.2` 식으로 **한 번만** 올려 재주행 |
| ④ quali-mini 드라이런 | 남은 시간 전부 | `./race.sh quali-mini` — Q1 2랩→Q2 2랩→Q3(버퍼 없음)로 축약된 실제 포맷 흐름이 새 맵에서 안 끊기는지 |

- [ ] ① **`./race.sh box --bag`**로 띄운다 (저속 `q1`이 아니라 `box`를 권장 —
      자율 속도는 0으로 묶이니 AMCL이 새 맵 원점에 잘 정렬되는지 먼저 안전하게
      RViz에서 본다). 어긋나 있으면 `./race.sh savepose`로 즉석 보정.
      **정렬 확인됐고 시간이 남으면** 조이스틱 **LB**(기본 버튼 4)를 눌러
      수동 조종으로 전환 — `map_server`/`AMCL`은 그대로 떠 있어서 RViz에
      맵+차 위치가 계속 보이고, `--bag` 덕에 `slip_friction`이 배경에서
      μ̂도 같이 모은다(맵핑 창에서 `joy2 --bag`를 못 했을 때 특히 유용).
      ⚠️ LB를 누르는 순간 조이스틱 자체 속도 상한(`joystick.max_speed`,
      지금 **7㎧**)이 그대로 걸린다 — box는 그 값을 안 낮춘다. RT를
      살살 당겨서 시작할 것. 조향 상한은 `pure_pursuit.max_steer`이고
      yaml엔 0.36으로 적혀 있지만 **실제 적용값은 차량 서보 실측 기반
      계산값**(`apply_vehicle.py`가 기동 로그에 찍어줌)이니 그 숫자를 믿을 것
- [ ] ② `./race.sh q1` — 아래 신호 중 하나라도 나오면 **그 자리에서 멈추고
      더 안 올린다** (0.1~0.2씩 조심스럽게, 대회에서 자주 쓰는 "0.5부터
      0.1씩" 절차를 5분 안에 다 못 하므로 **거칠게 압축**):
      - RViz 실주행 경로가 코너에서 흔들림(오실레이션)
      - `/drive`의 `steering_angle`이 `max_steer`에 계속 포화
      - 로그에 뜨는 `⚠ hard_cap 에 걸린 구간 N%`가 크게 뜸 (이 트랙엔
        hard_cap이 실제로 걸릴 수 있다 — 최근 그립 재측정으로 5→6까지
        올라간 상태이니 이 맵에서도 얼마나 잘리는지 로그로 확인할 것)
      - `./tune.sh --undo`로 즉시 롤백 가능
- [ ] ③ 한 단계만 더 올려 확인 — **정확한 물리 한계를 찾으려 하지 말 것.**
      대회 안전마진(한계×0.85)을 시간 안에 제대로 못 찾으니, 확인된 값보다
      **더 보수적으로** 두고 실전에 들어가는 쪽이 낫다
- [ ] ④ 남은 시간은 전부 `./race.sh quali-mini`에 쓴다 (연습 세션 5분엔
      규정 그대로의 `quali`(Q1 3랩→buffer→Q2 3랩→buffer→Q3, 최대 255초)가
      다 안 들어갈 수 있다 — `quali-mini`는 Q1/Q2를 2랩으로 줄이고 buffer도
      뺀 것으로, `race_script.yaml`은 안 건드리고 launch 인자로만 줄인다).
      grip_util 미세조정보다 **Q1→Q2→Q3 전환이 새 맵에서 안 걸리는지**(랩
      판정, AMCL 유지)가 대회 당일 가장 크게 사고 나는 지점이다. 실측치가
      조금 보수적이어도 시퀀서가 끝까지 도는 걸 확인하는 게 우선순위가 높다.
      시간이 넉넉히 남으면 마지막에 규정 그대로의 `./race.sh quali`도
      한 번 돌려볼 것 — buffer 구간(장애물 설치/제거용 저속 이동)은
      `quali-mini`에서 아예 안 도니 검증이 안 됐다
- [ ] 세션 끝나기 전에 최종 `config/vehicle_car2.yaml`(grip_util) 값을
      메모해 둘 것 — 저장 안 하면 다음 스택 재시작 때 날아가는 값은
      아니지만(파일이라 남음), 어떤 근거로 그 값을 골랐는지는 기록 안 하면
      잊는다

## 요약 — 시간 압박 시 절대 순위

1. **맵 저장** (savemap 없으면 전부 무효)
2. **레이싱라인 생성 + `--mu` 명시** (기본값 0.90 낙관 방지)
3. **start_pos** (없으면 연습 세션을 위치추정 디버깅으로 다 씀 — 이제 맵/
   웨이포인트 갱신까지 같이 해준다)
4. **grip_util 보수적 값으로 quali-mini 드라이런 완주**
5. grip_util 정밀 튜닝 / 규정 그대로의 `quali`(buffer 포함) 검증 ← 시간
   없으면 가장 먼저 버릴 항목들. 대회에서 안전 마진을 더 주는 게 몇 초
   빠른 것보다 낫다

## 이번에 새로 생긴 도구 (2026-08-24)

| 명령 | 용도 |
|---|---|
| `./race.sh joy2 --bag` | `slip`(원 그리기) 대신 — 평소 조이스틱 주행만으로 `slip_friction`이 μ̂ 자동 수집. 넓은 공간 불필요. 단 `map_server`/`AMCL`이 없어 RViz에 맵+차 위치는 안 뜬다 |
| `./race.sh box --bag` + LB | `joy2`와 달리 **전체 스택**(맵+AMCL)이 뜬 채로 시작 — 처음엔 자율 속도 0, LB(버튼 4)로 수동 전환하면 조이스틱으로 실제 주행하면서 RViz에 맵+위치가 계속 보이고 `slip_friction`도 같이 돈다. **위치추정 확인과 데이터 수집을 동시에** 할 때 이걸 쓴다. LB 전환 즉시 `joystick.max_speed`(현재 7㎧) 상한이 걸리니 RT는 살살 |
| `./race.sh quali-mini [컨트롤러]` | Q1 2랩→Q2 2랩→Q3, buffer 없음. `race_script.yaml` 안 건드림 |
| `./race.sh set_map [--map 이름]` | 맵/웨이포인트만 바꿈(init_pose 무관). 디스플레이 불필요, 순수 SSH에서 됨. joy2처럼 AMCL 안 쓸 때용 |
| `./race.sh start_pos` | (기존 기능 확장) 맵 고르면 `map_name`/`waypoints`까지 같이 갱신 |
