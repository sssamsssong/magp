## 1. 개요

- 모든 수준의 팀에게 열려있는 자율주행 레이싱 대회. 팀 인원 제한 없음, 단 한 사람은 한 팀만.
- 대면 경쟁: **2026-08-24 ~ 08-27, 부산 BEXCO, IFAC 2026 연계.**
- 단계: **0) 기술자료 제출 → 1) 등록·검사 → 2) 맵핑·연습 → 3) 예선(Q1~Q3) → 4) 일대일 경주**
- 참가팀은 직접 차량을 제작해야 하고, 팀마다 고유한 차량이어야 함 (한 연구실이 한 차로 여러 팀 참가 금지).
- 우승팀은 알고리즘 오픈소스 공개 권장 (의무 아님).

## 2. 기술 자료 제출

- 등록 절차에서 차량의 SW/HW 기술 요약 자료 제출. 형식 자유. 마감 엄수.

## 3. 등록 및 검사

### 3.1 차량 클래스

| 항목 | 규정 |
|---|---|
| 섀시 | 1:10 Traxxas 기준 (TRA74054, TRA6804R 권장). 치수 15% 이내면 대체 허용 — **폭 238~341mm, 길이 454~654mm**. 4WD/2WD 모두 허용 |
| 타이어 | 제한 없음 (스폰지·고무 모두 OK). **화학 첨가제 금지** |

| 카메라 | 단일/스테레오 모두 허용 (예: C270, C920, Pi Cam V2, Arducam, RealSense, ZED). **카메라 내부에서 검출·VIO 결과를 내는 카메라는 금지** (depth 정보는 허용) |

| 기타 센서 | IMU·엔코더·커스텀 ESC 허용. **실내 GPS(Marvelmind 등) 금지** |

**감지 박스 (Detection Box)** — ★ 중요, 상세는 아래 참고
- 지면 10~30cm **높이 구간 전체**에서, 그 안의 **모든 수평 단면**이 최소 12×12cm 사각형 이상이어야 함
- 즉 10~30cm(20cm 높이)를 통짜로 잇는 사각 기둥/틀을 세워야 하고, 어느 높이에서 잘라도 12×12cm 이상 유지
- **전/후/좌/우 4면 모두** 막혀 있어야 함 (3면만 막는 것 금지 — 상대 라이다가 뚫린 면으로 보면 감지 실패)

**폼 범퍼** — 손상 최소화용 부드러운 재질. 트랙에 2대 이상 있을 때는 감지박스·폼범퍼 **둘 다 부착 필수**.

### 3.3 검사

- 목적: 규정 충족 + 환경/상대/사람에 대한 위험 여부 확인

**3.3.1 소프트웨어 검사**

## 5. 예선 (미션 수행, 타임 트라이얼)

### 5.1 일반
- 연습·예선 동일 트랙 사용
- **각 단계 4분 이내** (참가팀 수에 따라 변동 가능) — ※ 2026-08-20 갱신, 구 규정 8분
- Q1 → Q2 → Q3 **순차 진행, 건너뛰기 불가**
- Q1/Q2/Q3 사이 **buffer lap 1바퀴씩** (장애물 설치/제거용)

### 5.2 예선 1 (Q1)
- 장애물 없는 트랙에서 **충돌 없이 3바퀴 완주**가 목표
- 미통과 시 **충돌 없이 완주한 바퀴 수**로 순위
- 통과하면 Q2로

### 5.3 예선 2 (Q2)
- **랜덤 정적 장애물(심판 배치, 총 2개)** 피해 3바퀴 완주가 목표. 위치 사전 미공지
- 미통과 시 완주 바퀴 수로 순위. 통과하면 Q3로

### 5.4 예선 3 (Q3)
- 장애물 없는 트랙, **1분간** 자유 주행 중 최소 랩타임 — ※ 2026-08-20 갱신, 구 규정 2분
- **사람 개입 시 그 랩타임 무효**

### 5.5 Fully Autonomous (달성 조건)
- 예선 전 과정에서 **차량에 직간접적 사람 영향이 전혀 없어야** 달성
- 직간접 영향 = 차량 터치 / 조이스틱 조작 / 키보드·마우스 터치 / 컴퓨터 조작
- **5초 이상 정지 상태가 되면(사람이 안 건드려도) FA 달성 실패** — Case 5 참고

### 5.6 정적 장애물
- Q2의 장애물은 정적 장애물. 상세 규정은 8절.

### 5.7 기록 무효
- 사람 개입 → 랩타임 무효 + 완주 바퀴 수에서 제외
- **정적 장애물 접촉 → 랩타임 무효 + 완주 바퀴 수에서 제외**
- 트랙 접촉이지만 사람 개입 없이 주행 지속 가능 → 경미한 접촉으로 간주, **기록 유효**

### 5.8 최종 순위 결정 (예선 기준)
순서:
1. Fully Autonomous 만족 여부
2. 통과한 예선 수

4. Q3 유효기록이 없고 Q1/Q2 동점이면 **검사(inspection)를 먼저 마친 팀이 우선**

## 6. 일대일 경주 (본선)

### 6.1 토너먼트 방식 — ★ 2026-08-20 갱신, 구 규정(더블 엘리미네이션)과 다름

- **Day 3(08-26): 그룹 스테이지** — 각 그룹 상위 3팀 선발
- **Day 4(08-27): 32강 브래킷**
- 참가팀 수에 따라 형식이 더 바뀔 수 있음 — **대회 초반에 최신 조 편성/브래킷을 반드시 재확인할 것**

### 6.2 일반
- 두 차량은 **서로 반대편 출발선**에서 시작
- **정적 장애물 3개** — 팀별 1개씩(양팀) + 심판 1개
- **선두 차량이 총 랩의 절반을 완주하면 장애물 전부 제거**

### 6.3 목표
- 먼저 10랩 완주가 기본, **8강 이후는 20랩으로 조정 가능** (초반 라운드는 짧게, 후반은 길게 — 구 문서와 서술 방향만 다르고 규칙은 동일)

### 6.4 무작위 정적 장애물
- 상세 규정 8절

### 6.5 충돌
- **트랙 경계·정적 장애물과 충돌**: 계속 주행 가능하면 **중단 없이 계속**
- **차량 대 차량**:
  - 심판의 정지 신호 없이 팀 재량으로 경주 중단 금지
  - 가해차량이 명확해도 추월 못 했으면 경기 그대로 진행
  - **피해차량이 명확 + 주행불가/충돌 심각/추월당함** → 경기 중단

### 6.6 주의 사항
- 감지 박스 규정 위반 차량은 **레이스 참가 불가**
- 나란히 달리다 생긴 접촉은 명확한 가해자 없으면 레이스 중지 안 함

## 7. 공통 주의 사항 (중요)

### 7.1 차량 연산·통신·제어
- **모든 연산은 차량 내부에서** 수행 (오프보드 연산 금지)
- **정상 주행 중 차량에 데이터 송신 금지**
- **정상 주행 중 킬스위치 작동 엄격 금지** — 안전 비상시에만, 충돌 회피 목적 금지 (3.3.1)
- **경주 중 조이스틱 사용/조작 금지**
  - 자율↔인간 전환 모듈은 **"누르고 유지" 금지, on/off 토글 방식**으로 구현할 것
- **시각화/디버깅용 랩톱 1대만** 연결 가능

### 7.2 안전
- 충돌로 주행이 어렵거나 위험하면 **즉시 비상정지**
- 사람이 트랙 위에 있는 것 금지
- 한 차량을 여러 팀이 공유 금지
- **트랙에 2대 이상 있을 수 있는 상황이면 감지박스 부착 필수** (예선은 부착 안 해도 됨)

### 7.3 트랙·장애물 처리
- 장애물에 너무 붙어 정지해 회피 불가 시 **뒤로 조금 이동 가능**
- **본선에서 장애물 충돌은 계속 주행 가능하면 문제없음** (예선 접촉 무효 처리는 5.7)
- 차량을 트랙에서 뺐다 다시 넣을 땐 **방향은 조정 가능하나 위치는 원래 자리**
- 트랙 접촉 시 (기록 무효 여부와 무관히) **즉시 원상복구**
- 장애물 접촉 시 **즉시 원위치 복구**

### 7.4 운영
- **Wi-Fi 이의신청 불가** — Wi-Fi 상황과 무관하게 독립 동작하도록 설계할 것. 비참가팀 Wi-Fi는 시각화/디버깅 편의상 꺼달라고 안내(알고리즘 성능과 무관)
- **트랙 내 하드웨어 수리/정비 전부 금지** (부품 수리, 센서 재보정, 배터리 교체 등)
- 맵핑/공식연습/예선 전용시간은 참가팀 수에 따라 변동
- 맵핑·공식연습 전용시간은 **선착순**, 등록·검사 완료 팀만 자격

## 8. 정적 장애물

**공통**
- 장애물 크기: **0.5m × 0.5m 미만**
- 장애물 제거는 차량에 영향 없을 때 안전하게 (레이스 상황상 다소 늦어질 수 있음)
- **충돌 후 장애물은 즉시 원상복구**, 복구 과정이 상대에게 영향 주면 안 됨
- **장애물 간 최소 거리 1m**
- **장애물이 있어도 트랙 폭 최소 0.5m는 항상 확보**

**예선 전용**
- 랜덤 장애물, 심판 배치, **총 2개**. 위치 사전 미공지. **Q2 완료 후 제거**

**본선 전용**
- **총 3개** (참가팀 각 1개 + 심판 1개)
- **선두가 절반 완주 시 제거**
- 장애물은 **양팀이 출발선에서 준비 완료한 후** 배치
  - **배치 후 코드 수정·경로 변경 금지**
  - 배치 후에는 **출발 신호만** 전달 가능
- **출발 위치 1m 이내에는 배치 불가**

## 9. 페널티

판정은 현장 심판 재량, 존중 필요. **한 사건당 페널티는 하나만** (여러 위반이 겹쳐도).

| 위반 사항 | 예선 | 본선 |
|---|---|---|
| 장애물 위치에 따른 사람의 경로 수정/선택 | 한 순위 강등 | 1랩 페널티 |
| 조이스틱·키보드·마우스 사용 [a] | 한 순위 강등 | 경고 |
| 충돌로 망가진 트랙을 적극 수정 안 함 [b] | 한 순위 강등 | 경고 |
| 부정 출발 | - | 경고 |
| 감지 박스 고정 불량 [c] | - | 경고 |
| 상대 차량에 대한 간접적 방해 [d] | - | 경고 |
| 경미한 후방 충돌 | - | 경고 |
| 상대 차량에 대한 직접적 방해 [e] | - | 1랩 페널티 |
| 큰 충격의 사고 유발 | - | 1랩 페널티 |
| 경고 3회 누적 | - | 1랩 페널티 |
| 페널티 랩 누적 3랩 | - | **실격** |

**세부**
- [a] 조이스틱/키보드/마우스 사용 **예외 허용**: 차량이 트랙 밖으로 빠진 경우 / re-localization용 initial guess 전송 / 심판이 레이스 중지 선언 후 비상정지 필요 시 / 출발·재출발 신호 전달 / 충돌로 주행 불가 상태의 비상정지 / **장애물에 5초 이상 갇혀 비상정지 필요 시** / 이상주행(역주행 등) 방지 비상정지 / 레이스 종료 후 정지
- [b] 트랙 미수정: 매 바퀴 새 경고 가능
- [c] 감지 박스 고정 불량: 매 바퀴 새 경고 가능
- [d] 간접적 방해: 트랙 수정하러 가다가 상대 감지 모듈에 걸려 상대 주행에 영향
- [e] 직접적 방해: 트랙 수정하러 가다가 상대와 물리 접촉해 영향

### 9.1 예시 사례

| 사례 | 예선 | 본선 |
|---|---|---|
| Case 1: 트랙 충돌, 자율 지속 가능 | 페널티 없음 (즉시 트랙 수정 필요) | 페널티 없음 |
| Case 2: 트랙 충돌로 주행 지속 불가 | 랩타임 무효 | 페널티 없음 (상대 영향 없을 때 트랙 수정) |
| Case 3: 충돌 후 조이스틱 매뉴얼 조작하며 경기 진행 | 랩타임 무효 + 한 순위 강등 | 경고 1회 |
| Case 4: 장애물 접촉/충돌 (강도 무관) | 랩 카운트 초기화 | 페널티 없음 |
| Case 5: 장애물 앞 5초 이상 정지 | **Fully Autonomous 달성 불가** | 페널티 없음, 차량 빼서 파라미터 수정 가능 |
