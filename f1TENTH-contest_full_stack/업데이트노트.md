## 2026-08-02
- **실물 크기 트랙 첫 테스트 주행 — AMCL 위치 오차가 누적돼 완전히 어긋남.** 소형 트랙(4.4×3.7m)에서는 벽이 코앞이라 스캔이 매번 교정해 가려져 있던 문제
- 원인 가설 ① `config/vesc.yaml` 의 `use_servo_cmd_to_calc_angular_velocity: true` — odom 각속도를 **서보 명령**에서 `ω=v·tan(δ)/L` 로 계산한다. 서보 지연 + 타이어 슬립(기구학 모델은 슬립각 0 가정) 만큼 **yaw 를 과대 적분** → "실제보다 더 많이 돌았다고 생각"하는 증상과 일치
- 원인 가설 ② IMU 미융합 — 입력이 휠 오도메트리 + 서보 명령 + 라이다뿐. 단 `vesc_driver` 는 이미 `requestImuData()` 로 `/sensors/imu`·`/sensors/imu/raw` 를 발행하도록 되어 있음 → **다음 세션 1순위: `ros2 topic hz /sensors/imu/raw` 로 보드에 IMU 가 실제로 있는지 확인**, 있으면 `robot_localization` EKF 로 wheel odom + IMU yaw rate 융합해 AMCL 입력 교체
- `amcl.yaml` 재검토 대상: `alpha1/alpha2 0.2`(회전 노이즈 과소) + `recovery_alpha_slow/fast 0`(전역 복구 없음) → 한 번 어긋나면 못 돌아옴
- **초기 포즈 정렬 방법 재확인: `./race.sh savepose`** — RViz `2D Pose Estimate` 로 맞춘 뒤 실행하면 TF `map→base_link` 를 읽어 `race_script.yaml` 의 `localization.init_*` 에 저장 (`/amcl_pose` 는 정지 중 발행 안 돼서 일부러 안 씀)
- `set_init_pose.py` 추가 — 맵 이미지에서 초기 포즈(위치+yaw)를 골라 `localization.init_*` 에 기록. 미리보기 PNG(1m 격자·축이 map 좌표) / `--x --y --yaw` / `--to-x --to-y` / `--wp N` / `--gui` 클릭, 주석 보존 줄단위 치환, 벽·맵밖 좌표 경고, `--also-start`/`--also-sim`
- sohot 트랙 추가 — `maps/sohot.*`(SLAM 원본)·`maps/sohot_clean.*`(정제)·`waypoints/sohot_clean_wp.csv`(401점)·Q2 경계 npy
- `race_script.yaml` — `map_name: sohot_clean`, `waypoints: sohot_clean_wp`, `controller: gap_follower`, `localization.init_*` = (-0.2184, -2.3503, -0.0082 rad) 하단 직선
